# BOSS 直聘海投 Agent（通用版）

把「逐岗看 JD → 按锁定话术写三段式沟通 → 发送 → 下一个」的海投流程打包成一个可复用的 Agent。
本包不含任何个人简历数据：简历部分留空，使用者上传自己的简历后，Agent 读取简历作为唯一事实来源，衔接整个流程产出沟通话术并执行投递。

## 包内容

- `agent-prompt.md`：Agent 主指令（角色、硬规则、停止条件、汇报规则），直接作为 Agent 的系统提示使用。
- `SKILL.md`：技能版流程说明，可放进 `~/workspace/custom-skills/boss_apply_agent/` 作为自定义技能加载。
- `workflow.md`：单岗 SOP 与列表衔接方法（主列表页锚点 + 岗位新开标签）。
- `templates/three-part-message.md`：三段式话术模板（占位符版，数字与经历从简历填充）。
- `config.example.yaml`：可调参数（目标岗位、列表顺序、每轮数量/不限量、跳过规则、期望薪资是否筛选）。
- `resume/RESUME_SLOT.md`：**简历留空位**。使用者把自己的简历放进 `resume/` 并按说明登记文件名，Agent 启动时先读它。

## 使用方法

1. 把简历 PDF 放到 `resume/`，在 `resume/RESUME_SLOT.md` 里写明文件名（或直接把简历全文贴入该文件）。
2. 按需改 `config.example.yaml`：目标岗位关键词、投递城市、列表顺序、是否不限量。
3. 把 `agent-prompt.md` 作为 Agent 指令加载（或安装 `SKILL.md` 为技能）。
4. 在**使用者自己的桌面浏览器**上登录 BOSS 直聘后，对 Agent 说「开始」。
5. Agent 按流程产出：逐岗三段式沟通并发送；只在平台限制、验证码、掉登录、发送失败或需要使用者拍板时打断汇报。

## 硬约束（流程内置，不可关）

- 只用使用者本人已登录的桌面浏览器；桌面浏览器不可用时停下，不用云端/手机网页版顶替。
- 话术只写简历里有的经历，参与/负责/主导的口径与简历原文一致，不虚构。
- 不打开消息栏，不读、不回复招聘者消息（由使用者本人处理）。
- 只统计浏览器确认「已发送/送达」的数量，未确认的单独标注，不凑数。
